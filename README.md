# 📱 Calculator App (React + Expo)

A simple and responsive calculator mobile application built using **React Native** with **Expo**.  
The app supports basic arithmetic operations with a clean and user-friendly interface.

---

## ✨ Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 🔢 Decimal support  
- ♻️ Clear / Reset functionality  
- 📱 Responsive UI for Android & iOS  

---

## 🛠️ Built With

- **React Native**
- **Expo**
- **JavaScript (ES6+)**

---

## 🚀 Getting Started

Follow these instructions to get the app running locally.

### Prerequisites

- Node.js (LTS recommended)
- npm or yarn
